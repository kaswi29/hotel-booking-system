# 🏨 StayEase – Hotel Booking Management System

A simple and responsive **Hotel Room Booking Management System** built using HTML, CSS, and JavaScript. This project helps manage hotel rooms, customer bookings, room availability, and booking revenue.

## 🌐 Live Demo

[View StayEase Live Demo](https://kaswi29.github.io/hotel-booking-system/)

## 📂 GitHub Repository

[Hotel Booking System](https://github.com/kaswi29/hotel-booking-system)

## ✨ Features

- **Dashboard:** View total rooms, available rooms, booked rooms, total bookings, and revenue.
- **Room Management:** Add, edit, delete, and manage hotel rooms.
- **Booking Management:** Create and manage customer reservations.
- **Room Availability:** Automatically update room status when a booking is created or cancelled.
- **Booking Search:** Search bookings using customer names or booking IDs.
- **Booking Cancellation:** Cancel existing reservations.
- **Automatic Price Calculation:** Calculate booking amounts based on room price and number of nights.
- **Data Storage:** Save room and booking information using Browser LocalStorage.
- **Responsive Design:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and responsive design
- JavaScript – Functionality and booking logic
- LocalStorage – Storing data in the browser

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/kaswi29/hotel-booking-system.git
   ```

2. Open the project folder:

   ```bash
   cd hotel-booking-system
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.

## 💾 Data Storage

This project uses **Browser LocalStorage** to store room and booking information.

- Data remains saved in the same browser on the same device.
- No backend or external database is required.
- Clearing browser data may remove saved project information.

## ⚠️ Project Limitations

- This is a beginner-level frontend mini-project.
- It does not include user authentication.
- Data is stored locally in the browser, not on a central server.
- Room availability uses a simple Booked/Available status rather than date-wise reservation tracking.

## 🎯 Project Objective

The main objective of this project is to understand and implement frontend web development concepts, JavaScript DOM manipulation, event handling, form validation, and browser LocalStorage through a practical hotel management application.
